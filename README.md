## Como acessar

O recrutador pode abrir qualquer projeto pela tabela acima e consultar o README específico de cada pasta. Os READMEs explicam a proposta, a tecnologia usada e como executar o projeto localmente.

Site institucional relacionado: [ITS COMPORTS](https://itscomports.com.br).

Os links online foram informados pelo proprietario dos projetos. Antes de enviar o portfolio, abra cada endereco para confirmar que o deploy esta ativo.

## Verificacoes

- Manifestos `package.json` validados.
- Scripts JavaScript verificados com `node --check`.
- Documentacao revisada e comandos alinhados aos scripts reais de cada projeto.
- Projetos React e Next.js prontos para instalar dependencias e executar os checks locais.

Para executar um projeto JavaScript, entre na pasta correspondente, rode `npm install` ou `pnpm install` conforme o README e depois use o comando indicado na documentacao.

## Sobre a organizacao

Os projetos estao reunidos neste repositorio para facilitar a apresentacao do portfolio. As pastas mantem suas estruturas originais para que cada entrega possa ser analisada separadamente.

Nao publique arquivos `.env`, credenciais, documentos de clientes ou planilhas reais.
