# Leo Celulares

Site institucional e comercial da Leo Celulares. A página apresenta a loja, seus serviços e formas de contato em uma interface leve, responsiva e pronta para publicação estática.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Netlify para publicação

## Desenvolvimento local

Como o projeto é estático, não há etapa de compilação. Abra `index.html` no navegador ou use qualquer servidor local:

```bash
npx serve .
```

## Estrutura

- `index.html`: página principal.
- `css/style.css`: estilos e responsividade.
- `js/main.js`: interações da página.
- `assets`: imagens e demais recursos visuais.
- `gerador-orcamento-leocelulares`: gerador de propostas usado como ferramenta auxiliar.
- `netlify.toml`: configurações de deploy.

## Deploy

O projeto pode ser publicado na Netlify como site estático. Aponte a publicação para esta pasta e mantenha `index.html` como arquivo de entrada.
